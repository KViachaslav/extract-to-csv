# extract-to-csv

Разбор PDF-выписки Альфа-Банка в простой CSV для бюджета, таблиц и дашбордов.

Скрипт `convert.py` **не требует сторонних библиотек** (только стандартная библиотека Python 3):
сам читает PDF, распаковывает `FlateDecode`-потоки, декодирует шрифты по `/ToUnicode` и
разбирает текстовые операторы (`Tf`, `Tm`, `Td`, `T*`, `Tj`, `TJ`), после чего собирает строки
таблицы операций по координатам колонок.

## Что получается на выходе

| Файл | Что попадает |
| --- | --- |
| `sell.csv` | расходы (сумма < 0) |
| `возвраты.csv` | поступления и возвраты (сумма ≥ 0) |

## Требования

* Python 3.8+ (проверено на 3.13);
* сторонние пакеты не нужны, `pip install` не требуется;
* в PDF-выписке должен быть текстовый слой (выписка из интернет-банка, а не скан).

## Запуск

```bash
# выписка расходы.pdf лежит рядом со скриптом
python convert.py

# или указываем файл явно
python convert.py путь\к\выписке.pdf
```

Имя файла по умолчанию задаётся константой `DEFAULT_PDF` (по умолчанию `расходы.pdf`) в начале
`convert.py`, поэтому выписку можно назвать как угодно и просто передать её путь аргументом.
Готовые `sell.csv` и `возвраты.csv` всегда пишутся в папку со скриптом.

В консоль печатается отчёт: сколько операций найдено, период, суммы расходов и поступлений,
а также список торговых точек, для которых в таблице категорий ещё нет правила.

## Формат CSV

```csv
date,amount,category

2026-08-31,12.5,Обед

2026-08-30,51.32,Коммуналка
2026-08-30,36.9,Пицца
```

* `date` — дата операции в формате `YYYY-MM-DD`;
* `amount` — абсолютная сумма (знак уходит в выбор файла), целые суммы пишутся без `.0`;
* `category` — категория из встроенной таблицы, а если правила нет — название торговой точки «как есть»;
* дни идут по убыванию, между днями — одна пустая строка;
* кодировка UTF-8 без BOM, переносы строк LF;
* поля с кавычками и запятыми экранируются по RFC 4180 (`"TC ""GALEREYA"""`).

## Как определяется дата операции

1. Если в описании операции есть 8-значная дата (`20260827`) — берётся она (это фактическая дата покупки).
2. Если такой даты нет (например, зачисления ЕРИП / через банкомат) — берётся дата проводки из левой колонки выписки.

## Категории

Категории задаются таблицей `CATEGORY_RULES` в начале `convert.py`. Проверка идёт
сверху вниз по вхождению подстроки без учёта регистра, поэтому более специфичные правила
должны стоять выше общих:

```python
CATEGORY_RULES = [
    ("TRANSPORT PAYBYCARD.BY", "Транспорт"),
    ("WHOOSH.BIKE", "WHOOSH"),
    ("YANDEX.GO", "YANDEXGO"),
    ("KAFE PICCA LISICCA", "Пицца"),
    ...
]
```

Чтобы добавить новую категорию, достаточно дописать строку в этот список — например:

```python
("AZS N29", "Топливо"),
```

После запуска скрипт сам подсказывает, какие торговые точки остались без правила, — удобно
постепенно дополнять таблицу под свои привычные места покупок.

## Структура репозитория

```text
convert.py     # весь парсер и логика категорий
README.md
.gitignore     # исключает *.pdf, *.csv и временные файлы
```

## Приватность

Файлы выписок (`*.pdf`), результаты разбора (`*.csv`) и текстовые дампы (`*.txt`)
**не попадают в репозиторий** — они перечислены в `.gitignore`. В git хранится только код.
